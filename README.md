# Ceviri

A lightweight web-based translation app built with plain HTML, CSS, and JavaScript.

## Features

- Translate text between common language pairs in the browser.
- Swap languages, copy results, listen to text, and download translations.
- Save recent translations locally in browser storage.
- Fall back to a small built-in phrase set if the online translation request fails.

## Running locally

Because this is a static app, you can run it with any simple file server.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in your browser.
